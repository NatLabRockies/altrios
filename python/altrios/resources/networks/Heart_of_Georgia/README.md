# Heart of Georgia network

`Heart_of_Georgia.msgpack` was built with `applications/network_builder` from
OpenStreetMap data and USGS 3DEP elevations; `Heart_of_Georgia_locations.csv`
gives one forward and one reverse dispatch row per terminal. Contains
information from OpenStreetMap, © OpenStreetMap contributors, available under
the Open Database License: https://www.openstreetmap.org/copyright.
